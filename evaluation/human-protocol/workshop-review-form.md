# Workshop review form (participant + observer)

Two short forms for the optional real delivery of the 90-minute workshop. Used **after** a session; results feed `docs/evaluation/revisions.md` and the workshop guide's "after the session" checklist. Anonymous by default; consent note applies (`consent-text.md`).

## A. Participant exit form (2 minutes, anonymous)

1. The session kept to its timings: agree / partly / disagree — where did it slip?
2. The stress-test demo landed its point: agree / partly / disagree
3. The AI-use levels (AIAS) were clear enough to apply to my own assignment: agree / partly / disagree
4. The redesign sprint was long enough to be useful: agree / partly / disagree — ideal length: ____
5. I am confident I will complete my one committed step: agree / partly / disagree
6. What almost didn't work for you in this session? (open)
7. What would you cut to make room for what you needed? (open)

## B. Facilitator/observer debrief (after the session, 10 minutes)

- Actual vs. planned timings per segment (fill from the agenda table):
  | Segment | Planned | Actual | Slipped because |
  |---|---|---|---|
  | S1 opening | 0–10 | | |
  | S2 demo | 10–25 | | |
  | S3 principles | 25–40 | | |
  | S4 break | 40–42 | | |
  | S5 sprint | 42–70 | | |
  | S6 gallery | 70–82 | | |
  | S7 close | 82–90 | | |
- Where did participants visibly disengage? ______
- Which pushback response worked / fell flat? ______
- Accessibility of the session (captions, materials in advance, read-aloud poll, canvas alternatives): what held, what failed? ______
- One change to the guide before the next run: ______

## What this evidence can and cannot show

- **Can:** timing reality, clarity of instructions, which segments need restructuring, confidence deltas (via the pre/post survey).
- **Cannot:** whether the redesigns improve student learning — that's the adopter's semester-level follow-up, and this kit makes no such claim.
