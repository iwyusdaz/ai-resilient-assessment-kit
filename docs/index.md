# Start here

**AI-Resilient Assessment Kit** — three common university assignments, stress-tested against generative AI, then redesigned with explicit AI-use levels, process evidence and new rubrics. Includes an approach comparison, a [decision tool](decision-tool/index.html) and a ready-to-run [90-minute faculty workshop](workshop/facilitator-guide.html).

**Evaluation status:** Automated accessibility testing and agent-based design reviews are complete. AI-simulated participant and review-panel evaluations are pending. No real participants have been involved. See [evaluation/METHODS.md](https://github.com/iwyusdaz/ai-resilient-assessment-kit/blob/main/evaluation/METHODS.md).

{: .note }
The whole kit is set at **Lakeside State University — a fictional US public university preparing for ADA Title II digital accessibility compliance.** The assignments, rubrics and numbers about enrolment are fictional but realistic; the frameworks and evidence base are real and cited.

## What problem this solves

Most AI-era assessment guidance is generic ("use more orals!", "ban AI"). It doesn't tell a lecturer *which* parts of *their* assignment AI can already do, *what to keep*, and *what to tell students*. This kit models the full diagnosis-then-design loop on three realistic cases:

1. **Stress test the original.** Run the brief through AI with three prompt strategies. Find out which rubric criteria AI satisfies easily. *(Protocol ready; results pending API keys — the vulnerability reasoning is available now, clearly labelled.)*
2. **Redesign deliberately.** Choose an AI-use level for every part of the task (using the [AIAS 2.1 levels](ai-use-levels.html)), move weight onto process and secure checks, and rewrite the rubric to reward what AI can't do.
3. **Make it usable.** Faculty notes with grading time and scaling options, student-facing briefs in plain language, and a workshop that walks colleagues through their own assignment.

## The three cases

| Case | Course | Original assignment | Redesign in one line |
|---|---|---|---|
| [A](case-a-essay/original.html) | SOC 101, first-year sociology | 1,500-word take-home argumentative essay | Staged build-up with a source-verification gate and a 5-minute defence |
| [B](case-b-problem-set/original.html) | STAT 201, introductory statistics | Take-home problem set (10 questions) | Open practice lane + weighted secure in-class checks + class-collected data |
| [C](case-c-research-report/original.html) | PSY 250, research methods | Lab-style research report from provided data | Student-collected data, lab notebook with dated entries, short structured Q&A |

## How to use this kit

- **If you teach:** start with [principles](principles.html), then read the case closest to your own course, then try the [decision tool](decision-tool/index.html) on your own assignment.
- **If you run faculty development:** take the [workshop](workshop/facilitator-guide.html) as-is — guide, slides, canvas, handout and survey are all included.
- **If you want the evidence trail:** the [literature notes](research/literature-notes.html) and the [stress-test protocol](research/stress-test-protocol.html) (now browsable on this site under Research), and [evaluation/METHODS.md](https://github.com/iwyusdaz/ai-resilient-assessment-kit/blob/main/evaluation/METHODS.md).
